### 💡 Core Exam Tips for These Subjects
*   **DBMS:** Practice SQL queries by hand and master Normalization step-by-step.
*   **Operating Systems:** Focus on numericals (CPU scheduling, Page replacement) and flowcharts/diagrams.
*   **Java:** Write code snippets on paper (if your exam is written) and focus heavily on OOP concepts and the Collections Framework.

### 🗓️ 7-Day Subject-Wise Breakdown

#### **Day 1: Fundamentals & Core Architecture**
*   **DBMS:** ER Model, Relational Model, Keys (Primary, Foreign, Candidate).
*   **OS:** OS Architecture, System Calls, Process State Diagram, PCB.
*   **Java:** OOPs Principles (Abstraction, Encapsulation, Inheritance, Polymorphism), Constructors.

#### **Day 2: Execution & Queries**
*   **DBMS:** Basic to Advanced SQL Queries (GROUP BY, HAVING, JOINs, Subqueries).
*   **OS:** CPU Scheduling Algorithms (FCFS, SJF, Priority, Round Robin — practice numericals).
*   **Java:** Abstract Classes vs Interfaces, Method Overloading & Overriding, `super` and `this` keywords.

#### **Day 3: Memory & Design Optimization**
*   **DBMS:** Functional Dependencies, Normalization (1NF, 2NF, 3NF, BCNF — practice conversion problems).
*   **OS:** Process Synchronization, Critical Section Problem, Mutex vs Semaphores, Classic Sync Problems (Producer-Consumer, Dining Philosophers).
*   **Java:** Exception Handling (`try-catch-finally`, custom exceptions), Memory Management (Heap vs Stack, Garbage Collection).

#### **Day 4: Deep Dive (Deadlocks & Collections)**
*   **DBMS:** Transactions, ACID Properties, Schedules (Serializability, Recoverability).
*   **OS:** Deadlocks (Conditions, Prevention, Avoidance — Banker’s Algorithm, Detection).
*   **Java:** Java Collections Framework Part 1 (List: ArrayList, LinkedList; Set: HashSet, TreeSet).

#### **Day 5: Advanced Topics**
*   **DBMS:** Concurrency Control Protocols (Lock-based, Timestamp-based), Indexing (B-Trees, B+ Trees concepts).
*   **OS:** Memory Management (Paging, Segmentation, Virtual Memory, Page Replacement Algorithms — FIFO, LRU, Optimal).
*   **Java:** Java Collections Framework Part 2 (Map: HashMap, TreeMap), Basics of Multithreading (`Thread` class, `Runnable` interface).

#### **Day 6: System Storage & Java Extras**
*   **DBMS:** File Organization, Hashing, Relational Algebra operators.
*   **OS:** File Systems, Disk Scheduling Algorithms (FCFS, SSTF, SCAN, C-SCAN).
*   **Java:** String Handling (`String` vs `StringBuilder` vs `StringBuffer`), I/O Streams basics, Practice 5 past year coding questions.

#### **Day 7: Full Mock & PYQ Revision Day**
*   **Morning:** Solve 1 Full Previous Year Question Paper for DBMS.
*   **Afternoon:** Solve 1 Full Previous Year Question Paper for Operating Systems.
*   **Evening:** Solve 1 Full Previous Year Question Paper for Java.
*   **Night:** Review mistakes made during mock tests and revise key formulas/diagrams.
